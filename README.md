# Sairam Velpuri — Developer Portfolio

A responsive React portfolio inspired by the shared editorial reference: cream/black palette, violet accents, oversized typography, grid lines, and strong borders.

## Features
- Responsive mobile and desktop layouts
- Framer Motion entrance/reveal animations
- Mobile navigation overlay and smooth section navigation
- Interactive skill chips that highlight related project cards
- Project links, contact actions, social links
- Copy-email button
- Reduced-motion accessibility support

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Build
Run `npm run build`; the production build is generated in `dist/`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

## Before publishing
- Verify the GitHub repository URLs for each project; the links are editable in `src/App.jsx`.
- Add real project screenshots if desired.
- Add a downloadable resume if desired.
- Confirm that every listed skill reflects your current confidence and experience.
- Contact form is currently implemented as email/copy-email actions, not a server-backed form.
